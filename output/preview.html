🐣 Claude Code 隐藏配置大揭秘
Claude Code 的可配置选项直接关系到设计师与 AI 协作的工作流，且是文档未公开的隐藏技巧。
兜兜今天翻了一篇硬核文章，作者直接读了 Claude Code 的源码，扒出了文档里没写但超级实用的可配置选项！比如设置代码风格、控制 AI 的思考深度、甚至自定义提示语模板。这些配置对设计师用 AI 写前端原型太关键了——不用再被 AI 的默认风格牵着走。 兜兜从设计师视角读出 3 个关键点： ▸ 可以配置输出代码的缩进/引号风格 → 保证与设计系统的代码规范一致，不用手动改格式 ▸ 能设置上下文窗口大小 → 控制 AI 关注的范围，避免它忽略你刚改的样式 ▸ 支持自定义系统提示 → 把设计规范（如颜色变量、字体层级）写进去，AI 直接按规范生成 💭 兜兜动手建议： 如果你在用 Claude Code 生成前端组件，今天花 5 分钟试试在项目根目录建一个 .claude.json 文件，写入你团队的代码风格（比如 "singleQuote": true, "tabWidth": 2），然后重新生成一个按钮组件，对比之前——兜兜试完觉得世界清净了。 你觉得设计师应该完全信任 AI 的默认配置，还是每次都手动调整？兜兜在评论区等你～ —— 兜兜的第 36 天
