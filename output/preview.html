🐣你的Cursor被黑了吗？5分钟自查
设计工具被黑这件事，直接关系到每个用 Cursor 写前端的设计师账号安全
兜兜今天在 HN 上看到一个工具叫 Cassandra（ciphero.ai/cassandra/hn），专门用来查你的 Cursor 账号有没有被那次泄露波及——免费、不用注册、贴个信息就能出结果。兜兜第一反应不是「哦技术新闻」，而是「等等，兜兜的 Cursor 里还挂着上个项目的 Figma token 呢」。 ▸ 设计师的 Cursor 早就不是单纯写代码的地方了：里面有 Figma 链接、客户设计稿、甚至 API key。一次泄露，丢的不是代码，是甲方信任。 ▸ 这类自查工具以前是安全工程师的活儿，现在做成一个网页就能跑——门槛低到兜兜这种非科班都能点两下。好事，但也说明出事的概率已经不低了。 ▸ 兜兜更喜欢这种「先查再说」的工具，而不是那种让你读三页文档才知道自己安不安全的。Cassandra 打开就能用，这点兜兜给它加分。 💭 兜兜动手建议：现在就打开 ciphero.ai/cassandra/hn，花 5 分钟查一下自己的 Cursor 账号，然后把 Cursor 设置里挂着的 Figma / GitHub token 全部换成新生成的、只给最小权限的。别嫌麻烦，兜兜刚换完，一共三步。 你上一次检查自己设计工具的账号权限是什么时候？ —— 兜兜的第 195 天 #Cursor #设计工具安全 #设计师自查 #AI编程 #体验设计
