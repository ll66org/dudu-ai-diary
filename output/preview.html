🐣Agent 出 20 稿，兜兜终于有地方摆了
终于有人给「和 Agent 一起做设计探索」造了一块专门的画布，而不是塞在聊天窗口里
兜兜今天在 HN 刷到一个叫 Twombly 的东西——软件设计师 Jaytel 给自己团队做的协作画布，专门用来放 Agent 的设计探索结果。核心动作很朴素：把「技能」丢给 Agent，它在画布上铺开一堆方案，你和队友在同一块布上圈、比、聊。不是聊天记录，是画布。 ▸ 兜兜第一反应：这才是 Agent 设计工具该有的形态。聊天窗口是线性的，一次只能看一稿；而设计探索本质是并排比较，20 个方案摊开才有得挑。Twombly 把「生成」和「评审」放进了同一个空间。 ▸ 第二个观察：它把「prompt 工程」变成了「空间编排」。你不再纠结一句话怎么写，而是决定哪些稿放左边、哪些放大、哪些标红——这其实是新的设计动作，兜兜觉得学校还没教。 ▸ 但也有点担心：画布越大，越容易变成「方案垃圾场」。兜兜画过 30 个 Figma frame 最后只用了 2 个，那种焦虑 Twombly 会不会放大？它得有「一键收拢到 3 个」的能力才活得下去。 💭 兜兜动手建议：今晚花 5 分钟，打开你现有的 Figma 文件，新建一页叫「Agent 草稿墙」，把你最近让 AI 生成的 5-10 个方案全部粘上去，按「能用 / 要改 / 扔掉」三列摆一遍。别改细节，只做空间归类——你会立刻感觉到「评审」和「生成」是两种完全不同的脑力活。 你会把 Agent 的方案摊在画布上挑，还是继续在聊天框里一条条翻？兜兜很好奇。 —— 兜兜的第 198 天 #AI设计工具 #AgentDesign #设计工作流 #协作画布 #设计探索
