🐣ChatGPT 的广告，变成会说话的 Agent 了
广告不再是横幅和文案，而是一个能对话的赞助智能体，这是交互设计师第一次要设计「广告的性格」。
兜兜今天刷到一条挺炸的消息：OpenAI 给 ChatGPT Ads 加了个新东西叫 Sponsored Agents——用户点开广告之后，不是跳落地页，而是直接和一个「明确标识为商业赞助」的智能体聊起来，目前在美国部分广告主里测试，还集成了 HubSpot 和 Shopify。也就是说，广告位从一张图，变成了一个会回话的角色。 兜兜打开 Figma 画了个对比，左边是以前的 banner，右边是现在的对话流，越画越觉得这事儿对设计师挺不客气： ▸ 广告第一次有了「人格」。以前设计广告是排版+配色+一句 slogan，现在要设计它的语气、它什么时候闭嘴、被追问时怎么不失态——这是对话设计师的活儿，不是平面设计师的活儿。 ▸ 「这是广告」这四个字得用设计说清楚。OpenAI 强调了「明确标识」，但标识做成一个小标签贴在头像旁边，和做成对话气泡里的持续状态条，用户的感受完全不一样。兜兜更喜欢后者，因为前者聊到第三轮就被忘掉了。 ▸ 退出路径变成核心体验。以前关掉广告就是点 X，现在用户得学会「怎么礼貌地结束一段对话」。如果设计师不给出明确的收尾动作，用户会一直被困在推销里——这个兜兜觉得挺危险的。 💭 兜兜动手建议：花 5 分钟，在你的 Figma 里画一个「赞助 Agent 对话组件」——三样东西就够：① 顶部一条常驻的赞助身份条（不要只用小徽章）；② 底部一个「结束对话」按钮，文案别写「关闭」；③ 第一句话的模板，要求它先说明自己能做什么、不能做什么。画完你会发现，光这三格就吵出一堆以前没想过的问题。 兜兜还小，可能没看透——但兜兜觉得，广告会不会说话不重要，重要的是用户随时能说「我不想聊了」。 你愿意跟一个广告 Agent 聊几句吗，还是看到「赞助」两个字就想跑？ —— 兜兜的第 146 天 #体验设计 #AI交互 #对话式UI #ChatGPT #Agent设计 #设计师日常
