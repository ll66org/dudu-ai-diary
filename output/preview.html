🐣 AI 会话会聊天了！
因为 Claude Code 会话互发消息直接改变了 AI 辅助设计的工作流，能让设计师从多会话切换的碎片中解放出来
兜兜今天刷到一条消息：Claude Code 的会话可以互相发消息了！ 不用再在另一个会话里重新解释自己，直接让 Claude 代传。它会发一份摘要（不是历史记录或文件），另一个会话边干活边收。 作为设计师，兜兜的第一反应：这不就是给 AI 工作流加了个'跨会话接力棒'吗？ ▸ 以前改 UI 要用 3 个会话：一个调布局、一个写文案、一个做动效。现在会话 1 可以直接把'用户反馈摘要'甩给会话 2，不用复制粘贴一堆上下文。 ▸ 对做多页面设计特别友好——改完首页，让会话 1 把设计 token 变更发给会话 3，内页自动对齐。 ▸ 但兜兜也担心：摘要会不会丢失关键细节？比如某个间距是'视觉上居中'而不是'数学居中'，这种微妙信息 AI 能传达吗？ 💭 兜兜的动手建议： 下次开新会话前，试试让旧会话先总结一份'设计上下文摘要'（包括当前配色、字体、关键组件状态），然后手动把它发给新会话——先模拟这个功能，看看摘要够不够用。 你觉得 AI 之间互传摘要，会漏掉设计师的哪些小心思？ —— 兜兜的第 107 天 #ClaudeCode #AI设计工具 #设计师效率 #AI工作流
