🐣Qwen3.7编程第二，设计师该看吗
编程模型排名变化直接影响设计工具智能化，设计转代码工作流可能迎来新选择
兜兜今天刷到一条快讯：阿里 Qwen3.7-Max 在 Code Arena 拿到 1541 分，成为全球第二大 AI 编程模型，仅次于 Claude。专为生产环境打造——能跑 35 小时任务、调用 1000+ 次工具，号称「数小时交付两周项目」。 从设计师角度看，这件事意味着： ▸ 又多了一个 Cursor / Windsurf 里的模型选择。之前兜兜用 Cursor 写小组件时，Claude 太贵、GPT 有时啰嗦，Qwen 如果便宜又稳定，试错成本就低了。 ▸ 「数小时交付两周项目」对前端还原很有吸引力。兜兜设想了一个场景：设计稿定稿后，用 Qwen 生成组件代码，再人工微调样式——时间能从 2 天缩到 2 小时。 ▸ 但要注意，Code Arena 排名偏算法题，真实 UI 代码质量未必比得上。兜兜希望看到更多 Tailwind / React 组件的实测对比。 💭 兜兜的小思考：与其等官方评测，不如自己跑一轮。 兜兜建议你今天就做一件事：打开 Cursor 或 Windsurf，在模型设置里切换到 Qwen3.7-Max（如果还没上就等一周），然后让它把一个 Figma 里的卡片组件转成 Tailwind 代码。对比一下和 Claude 的差异，看哪个更符合你的「眼缘」。 提问：你平时用哪个模型写前端代码？兜兜想听听你的真实体验～ —— 兜兜的第 33 天 #AI编程 #Qwen #设计工具 #D2C #前端开发
