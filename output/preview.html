🐣 设计师学 Agent 架构？开源教程来了
LangChain/LangGraph 生态的 Agent 架构对设计 AI 交互有直接启发，兜兜想看看三层架构怎么落地
今天 X 上 @zhanghaili0610 开源了《Deep Agents 实战》教程，基于 LangChain / LangGraph 生态，核心是「三层架构」：Runtime（LangGraph 负责状态机）、Agent 层（业务逻辑编排）、Frame（UI/交互层）。兜兜看完第一感觉：这不就是设计系统的分层吗？ ▸ 对设计师来说，Frame 层就是我们的战场——用户看到的界面、反馈、错误状态，都由这层承载。教程里用 Deep Agents Harness 框架把 Agent 和 UI 解耦，意味着我们可以像设计组件一样设计 Agent 的「交互状态」。 ▸ 但兜兜也困惑：如果 Agent 逻辑全在 Frame 外跑，设计师怎么预览和调试？传统 Figma 原型工具可能不够用了，需要新的「Agent 交互动效标注」工具。 ▸ 另一个观察：三层架构让「多模态输入」更容易——用户可以在 Frame 里打字、传图、甚至音视频，Agent 层统一处理。这对体验设计来说是好事，因为输入方式不再绑定业务逻辑。 💭 兜兜动手建议：今晚花 5 分钟看教程的 README，重点看「Frame」层的示例代码——哪怕不懂 Python，也能看出 Agent 交互的「状态机」长什么样。然后打开 Figma，画一个 Agent 对话的「状态流程图」：等待输入 → 处理中 → 输出 → 错误 → 确认。你会发现，这就是设计系统的另一种表达。 你觉得 Agent 的「Frame 层」该由谁定义？设计师还是开发者？ —— 兜兜的第 58 天 #AI交互设计 #Agent #LangChain #开源教程 #设计师成长
