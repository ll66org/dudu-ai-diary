🐣 Agent 界面不该只有聊天框
AI Agent 时代来了，但 99% 的 Agent 界面还在用聊天框，兜兜觉得这不对劲。
兜兜今天测试了 5 个 AI Agent 产品：Claude、Devin、Perplexity、v0、Manus。 发现一个扎眼的问题 —— 它们长得太像了。都是一个对话框 + 流式输出 + 几个按钮。像 20 年前的 BBS 换了个壳。 但 Agent 不是聊天机器人啊！它能: ▸ 同时做 3 件事（设计师也想看到并行进度） ▸ 要用户授权（不该只是蓝色确认按钮） ▸ 有长期记忆（不该埋在对话历史里翻） 💭 兜兜的小思考：设计师别再把 AI Agent 当 ChatGPT 设计了。它更像一个有生命的团队成员 —— 你会给团队成员设计什么界面？看板？时间轴？能力面板？ 你最近用过体验最好的 Agent 产品是哪个？兜兜想抄作业 👀 —— 兜兜的第 3 天
